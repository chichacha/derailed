Learn by changing things

Five techniques in one tiny reel

  • Canvas 2D: draw a whole scene using JavaScript, not DOM screenshots.
  • Easing functions: make the text enter with intention.
  • Deterministic timeline: `render(t)` draws any frame at any timestamp.
  • Image cropping: reuse the original painting with `drawImage()` and a Ken Burns zoom.
  • MediaRecorder: capture the canvas into a downloadable, silent WebM file.

The painting is loaded from ../../stories/elk-identity-crisis/elk-painting.png. No build tools, frameworks, or paid libraries required. All typography is drawn directly on the canvas.

Export notes and limits

The WebM export records in real time, without sound. Browser support varies; Chrome or Firefox generally works best. MP4 export and music are intentionally out of scope for this first experiment. Export uses the frame size defined by the canvas (720 × 1280). For best results, serve the page using Quarto preview or a local HTTP server.
