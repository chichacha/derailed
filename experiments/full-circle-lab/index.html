01 / Read the circle

Digits become relationships.

Every digit owns a sector. If 1 is followed by 4, a thread runs from 1 to 4. Repeated transitions create density. Threads retain individual occurrences; ribbons aggregate them into directed flows, whose sector sizes reflect the total incoming and outgoing counts. Select any digit to isolate outgoing transitions.

02 / Read the evidence

Patterns are not proof.

These are finite prefixes, not evidence that a constant is normal or random. Frequencies and transition counts describe only the selected prefix. The constants are computed locally using BigInt fixed-point arithmetic, with 40 guard digits; no external digit dataset is needed.
